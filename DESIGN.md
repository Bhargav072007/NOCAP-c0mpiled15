# NoCap interface

A focused research workspace for collecting original evidence, reviewing it as a team and inspecting audit records. One connected source; no device fleet navigation. Preserve the real token sign-in and explicitly labelled local demo.

Warm charcoal `#121410`, raised neutral `#1b1e18`, primary text `#f3f0e7`, secondary text `#b1b5a9`, sage action `#c1d6a5`. Reserve semantic red/amber for actual status. Instrument Sans for UI, Newsreader italic only for the landing headline. Minimum 13px for ordinary body/caption text; smaller metadata is limited to compact preview labels. Tabular numeric metrics. Thin rules establish groups; avoid nesting decorative panels.

Use 160ms control feedback and 180ms result arrival. Frequent navigation stays stationary. The 15-second illustrative workflow tour uses perspective and opacity, with manual steps and pause. The ambient ribbon is decorative, never a loading/verification indicator. System and saved reduced-motion preferences take priority.

CSS loads fonts, existing base styles, motion, demo geometry, then refinement tokens/layout. The final refinement layer preserves Streamlit control contracts. See `docs/design-sources.md` for upstream references and adaptation licenses.

UI-M3 adds an explanatory evidence-flow illustration to the home page and a compact version above overview metrics. Native surface pause controls stop continuous decorative motion. Pointer-only feedback enhances metrics, review rows, avatars and uploads without moving data. Dialogs use a 250ms starting-style transition. The final `lively.css` layer extends existing motion tokens; manual and OS reduced-motion settings take precedence.
